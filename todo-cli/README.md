# Todo CLI 📝

A command-line todo manager built with Go.

## Features
- ✅ Add new tasks
- 📋 List all tasks with colors
- ✓ Mark tasks as complete
- 🗑️ Delete tasks
- 🧹 Clear all tasks
- 💾 Persistent storage (JSON)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/todo-cli.git
cd todo-cli
